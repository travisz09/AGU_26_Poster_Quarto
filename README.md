# AGU 2026 Poster

Supplemental materials for my AGU 2026 poster.

This Quarto website provides additional figures, methods, and supporting information associated with the poster.

## View the Website

**[AGU 2026 Poster Supplemental](https://travisz09.github.io/AGU_26_Poster_Quarto/)**

## Repository

The website is built with [Quarto](https://quarto.org/) and automatically published to GitHub Pages using GitHub Actions.

### Local Preview

```bash
quarto preview
```

### Render

```bash
quarto render
```
